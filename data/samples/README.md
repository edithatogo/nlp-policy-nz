# Demo fixtures

The text files in this directory are repository-authored synthetic smoke
fixtures. They are released under the repository MIT license, are intended
only for local demonstrations and contract tests, and are **not** held-out
evaluation data.

These fixtures must not be used to support empirical accuracy, rights, or
adoption claims. Held-out evidence is tracked separately in
`data/adoption_readiness.json` and the linked Track 96-98 artefacts.
